# Raw data (not committed)

Source: Kaggle competition "IEEE-CIS Fraud Detection"
(https://www.kaggle.com/competitions/ieee-fraud-detection). The data belong to the provider and are
used under the competition rules; they may not be redistributed, so nothing in this folder is
committed except this file.

## How to get it

1. Sign in to Kaggle and accept the competition rules on the competition's Rules tab.
2. Download `train_transaction.csv` and `train_identity.csv` (Data tab) into this folder.
   The test files are not used.
